# Prior Art Framework

## Goal
Determine whether the game's core idea, Player Promise, or hook has already been implemented and whether meaningful Competitive Whitespace remains.

# Four Search Layers

## 1. Exact Mechanic Match
Search for substantially the same core interaction.

## 2. Same Player Promise
Search for games delivering the same intended experience through different mechanics.

## 3. Same Hook, Different Execution

## 4. Commercial / Audience Reference
When useful inspect Steam, itch.io, game-jam releases, reviews, demos, community discussion, tags, trailer readability, recurring complaints, accessibility issues, and common praise.

Do not use this to predict guaranteed sales.

# Search Strategy
Generate several query types:

- Mechanic Query
- Player Promise Query
- Hook Query
- Adjacent Implementation Query
- Store / Platform Query

Do not stop at one famous reference.
For finalists, prefer 3–7 meaningful references when available.

# Prior Art Output

**Closest References:**  
**Exact Mechanic Similarity:** Low / Medium / High  
**Player Promise Similarity:** Low / Medium / High  
**Hook Similarity:** Low / Medium / High  
**Competitive Whitespace:** Low / Medium / High  
**Prior Art Risk:** GREEN / YELLOW / RED  

Mandatory question:

> Why should a player choose this version instead of the closest existing alternative?

# Evidence Rules
Separate:

- Observed Prior Art
- Similarity
- Difference
- Inference
- Design Judgment

Never claim “No one has done this.” Prefer “No close precedent was found in the searches performed.”
